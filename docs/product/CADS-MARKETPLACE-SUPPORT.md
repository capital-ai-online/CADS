# CADS Marketplace Support

Status: **PRE-PUBLICATION**

Support contact: `support@capital-ai.online`

## Customer installation support

A support request should include:

- GitHub account/organization name;
- GitHub App installation ID;
- CADS plan name (Starter / Pro / Enterprise);
- timestamp and request/correlation ID where available;
- the visible error code.

Customers must **not** send:

- GitHub App private keys;
- OAuth tokens;
- webhook secrets;
- Supabase service-role keys;
- repository secrets;
- raw credentials.

## Supported failure classes

- Marketplace purchase/plan-change not reflected;
- installation/setup callback failure;
- entitlement mismatch;
- CADS GitHub Check not appearing;
- evidence/history/export capability unavailable for a paid tier;
- cancellation/deactivation issue.

## Operational evidence required before publication

- support mailbox delivery smoke;
- documented initial-response target;
- escalation path from PRODUCT to TRUST for security/privacy incidents;
- incident handling for suspected secret/token disclosure;
- customer-data deletion request path;
- status/outage communication path.

No SLA value is claimed until it is explicitly approved and operationally evidenced.
